# Silicon Witchery Homebrew tap

Homebrew casks for Silicon Witchery software. The contents of this repository
are generated on release by GoReleaser. Do not edit them by hand.

## Superstack CLI

```sh
brew install --cask siliconwitchery/tap/superstack
```

To upgrade:

```sh
brew upgrade --cask superstack
```

Source and issues: [siliconwitchery/superstack-cli](https://github.com/siliconwitchery/superstack-cli)
